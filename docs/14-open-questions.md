## Информационная архитектура

### Согласовано

- **Табы:** 5 — Главная, Курс, Словарь, Грамматика, Тексты. Повторение — stack-режим, не таб; настройки — stack с Главной.
- **Курс:** один курс «Японский» с уровнями N5/N4/N3; уровни содержат разделы, разделы — уроки.
- **Списки справочников:** один список с фильтрами «Все/Пройдено» и бейджами, без двух копий.
- **Словарь:** по умолчанию личный; поиск по глобальному; личные слова помечены цветом и прогрессом. Сортировка по добавлению/прогрессу/алфавиту; без группировки по уровню.
- **Авторство:** JSON + CLI-валидатор; in-app редактор не нужен в ближайшее время.
- **Модель урока:** общий lesson runner; грамматика/слова/текст/аудирование позже; отдельный урок повторения не нужен.
- **Повторение:** после каждого урока, до 10 слов за сессию (лимит настраиваемый); глобальная кнопка на Главной.
- **Прогресс слова:** статусы «Новое / Учится / Закрепляется / Уверенно» на основе FSRS, без сырого процента.
- **Название раздела:** «Библиотека».
- **Курсы:** отдельные языковые пары (`ja-ru`, позже `ja-en`), без мультиязычных полей внутри одного курса.
- **UI-язык:** определяется языком системы с fallback на `ru`; поддерживается только `ru`; UI-язык не равен source language контента.
- **Контент:** пока только для русскоязычных; `sourceLanguage: ru`.
- **Zod:** используем для валидации course packs и вывода типов.

### Открыто

- **Хранение прогресса:** отдельные типизированные таблицы по доменам или одна `user_item_progress`.
- **Пороги прогресса:** точные значения stability/state после первых данных.
- **Уровень слова:** не группируем; JLPT-уровень для всего JMdict пока не гарантирован.
- **Лимит повторения:** 10 слов — стартовое значение; нужна ли настройка в MVP?
