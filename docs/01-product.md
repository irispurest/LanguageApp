# 01. Продукт

## Видение

Офлайн-приложение для изучения языков, которое не заставляет выбирать между «только слова», «только грамматика» и «только тексты». Это среда, где уроки, тесты, словарь, чтение и интервальные повторения работают вместе, но каждая сессия остаётся короткой.

Первый язык — японский. Архитектура при этом не должна быть одноразовой: ядро проектируется так, чтобы позже можно было добавить другой язык как course pack + language adapter, не переписывая приложение.

## Пользователь

- Русскоязычный учащийся, уровень примерно N5+.
- Учится самостоятельно, часто короткими сессиями: в дороге, на перерыве, без интернета.
- Хочет не «ещё один тренажёр», а личную среду: грамматика, словарь, тексты, повторение.
- Параллельно учит React Native и хочет понимать, как устроен код.
- Не хочет обязательную подписку, аккаунт и постоянный онлайн.

## Проблема

Популярные приложения для японского часто:
- узконаправлены (только кана, только слова, только чтение);
- платные или ограничивают бесплатный режим;
- требуют интернет;
- перегружены функциями, которые не нужны для короткой сессии;
- плохо связывают текст, словарь и повторение.

## Принципы продукта

1. **Offline-first.** Основные сценарии работают без сети. Сеть может понадобиться только для необязательной загрузки контента позже.
2. **Короткая сессия.** Любой экран должен позволять закончить за 2–10 минут и сохранить прогресс.
3. **Игра, но не игрушка.** Понятная обратная связь, прогресс и небольшая доля азарта без бесконечных наград и давления.
4. **Универсальное ядро.** SRS, прогресс, упражнения и навигация не знают про японский. Японская специфика — в адаптере и контенте.
5. **Контент как данные.** Уроки и тексты лежат в course packs, а не в JSX. Новый урок не должен требовать правки экранов.
6. **Один экран — одно действие.** Не превращать приложение в комбайн.
7. **Прозрачность.** Пользователь видит, что учил, что повторять и откуда взялось слово.
8. **Уважение к данным.** Прогресс хранится локально, миграции не теряют историю, есть путь к экспорту.

## Пользовательские сценарии

### Сценарий 1. Короткая грамматическая сессия
Пользователь открывает приложение в метро без сети. На главной видит «Продолжить урок». Проходит объяснение, 5–7 упражнений, получает результат и возвращается на главную. Прогресс сохранён.

### Сценарий 2. Слово из текста
Пользователь читает короткий текст. Нажимает на незнакомое слово. Открывается словарная карточка: чтение, значение, часть речи, пример. Он добавляет слово в колоду. Слово появляется в повторениях.

### Сценарий 3. Повторение
На главной видно количество карточек к повторению. Пользователь проходит очередь, оценивает ответы, видит следующие интервалы. Всё работает офлайн.

### Сценарий 4. Словарь
Пользователь ищет слово по кандзи, кане или русскому значению, открывает статью и добавляет слово в колоду вручную.

### Сценарий 5. Проверка приложения и курса
Так как пользователь уже знает N5-грамматику, первый курс собирается из знакомых тем. Это позволяет проверять UX, упражнения и контент, не отвлекаясь на изучение нового материала.

## Границы первого этапа

В первый вертикальный срез входит:
- одно приложение на Expo/React Native/TypeScript;
- Android-телефон через Expo Go;
- 1–2 грамматических урока уровня N5 (знакомые темы);
- три типа упражнений: выбор варианта, пропуск из банка, упорядочивание;
- сохранение прогресса в SQLite;
- офлайн-работа;
- тесты на проверку ответов и валидацию контента.

Не входит:
- iOS;
- бэкенд, аккаунты, синхронизация;
- словарь и тексты (следующие этапы, но модель данных готова к ним);
- SRS (следующий этап, но схема данных готова);
- аудио, рукописный ввод, кандзи-stroke order;
- визуальный конструктор курсов;
- монетизация, аналитика, соцфункции.

## Критерии успеха первого среза

- Приложение запускается на Android-телефоне через Expo Go.
- Урок проходится полностью без сети.
- После перезапуска приложения прогресс и ответы на месте.
- Все три типа упражнений работают и дают понятную обратную связь.
- Новый урок добавляется через JSON-контент и валидатор, без правки кода экранов.
- `lint`, `typecheck` и тесты проходят.
- Пользователь может объяснить, как устроены данные и поток урока.

## Контентная политика

- Первый курс — учебный полигон: знакомые N5-темы, а не новая для пользователя грамматика.
- Объяснения и переводы — на русском.
- Примеры — с японским текстом, чтением и переводом.
- Одна грамматическая точка = один урок с небольшим набором упражнений.
- Не использовать спорные/неоднозначные формулировки, где возможны два правильных ответа.
- Сторонние тексты, словари и примеры — только с проверенной лицензией и атрибуцией.

## Что должно остаться после MVP

- Возможность добавить второй язык без клонирования приложения.
- Возможность обновлять словарь и course packs версиями.
- Возможность экспортировать прогресс.
- Понятная база для C#-бэкенда, если синхронизация когда-нибудь понадобится.
