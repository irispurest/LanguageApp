# 10. UX и UI

> **Статус: IA согласована в общих чертах (2026-11-21).** Пять вкладок: Главная, Курс, Словарь, Грамматика, Тексты. Повторение — режим, не отдельный таб. Текущий app shell ещё отражает старый черновик; код будет перестроен после согласования схемы контента.

## Принципы

1. **Короткая сессия.** Главный экран сразу предлагает продолжить урок или повторение.
2. **Одно действие.** На экране не должно быть двух равнозначных «главных» кнопок.
3. **Спокойная игра.** Прогресс и обратная связь — есть; бесконечных наград, таймеров и наказаний — нет.
4. **Ясность.** Пользователь понимает, что произошло и что дальше.
5. **Офлайн.** Нет экранов, которые ломаются без сети; нет «загрузка...» из ниоткуда.
6. **Доступность.** Крупные цели, читаемый контраст, системный размер шрифта.

## Навигация

### Целевая

Нижние вкладки:
- **Главная** — следующий урок, due-повторение, краткая статистика, вход в настройки.
- **Курс** — чистый список уровней, разделов и уроков; без дашборда.
- **Словарь** — по умолчанию личный словарь; поиск переключается на глобальный.
- **Грамматика** — все темы / пройденные.
- **Тексты** — все тексты / прочитанные.

Повторение — **не таб**, а отдельный stack-экран/режим. Запускается с Главной, после урока, в конце раздела или из словаря.

Настройки/О приложении — stack-экран, вход с Главной.

### MVP

Показываем все пять вкладок; если раздел ещё не готов, честный empty state. Повторение доступно из Главной и из урока, даже если отдельного таба нет.

## Экраны

### Главная
- «Продолжить» — следующий урок.
- «Повторить слова: N» — запуск общего review-режима, без перехода в словарь.
- Краткая статистика: уроки, слова, серия (минимум).
- Настройки/О приложении — иконка в шапке.
- Быстрые ссылки на словарь/грамматику/тексты.
- Никаких простыней статистики в MVP.

### Курс
- Уровни N5/N4/N3 (в одном курсе), разделы, уроки.
- Чистый список: тип урока, название, статус.
- Прогресс/галочки завершения, но без статистических виджетов.
- Переход к уроку; «Продолжить» остаётся на Главной.
- Повторение в конце раздела — действие, не отдельный урок.

### Урок
- Заголовок, цель.
- Блоки объяснения и примеры.
- Прогресс по шагам.
- Выход с сохранением.
- Кнопка «Дальше» всегда на виду.

### Упражнение
- Инструкция.
- Вопрос/предложение.
- Варианты/банк/токены.
- После ответа: подсветка, объяснение, «Дальше».
- Не показывать правильный ответ до ответа пользователя.

### Итог урока
- Счёт.
- Список ошибок с краткими пояснениями.
- «Повторить» / «На главную».

### Словарь
- По умолчанию открывается **личный словарь**.
- Сортировка: по времени добавления / по прогрессу / по алфавиту. Без группировки по уровню (уровень не гарантирован для всех слов).
- У каждого слова — прогресс изучения (4 статуса/полоса, не сырой процент).
- Поиск переключается на глобальный словарь; найденные личные слова помечены цветом и прогрессом.
- Статья: значения, части речи, кнопка добавления/повторения.
- «Повторить слова» — запуск review-режима.
- Полный глобальный список не рендерить целиком: только поиск/выдача с лимитом.

### Грамматика
- Один список тем: фильтр «Все» / «Пройдено».
- Пройденные помечены бейджем/цветом; порядок по умолчанию стабильный.
- Тема: объяснение, примеры, кнопка «Отметить пройденной».
- Курс автоматически отмечает тему пройденной после урока грамматики.

### Тексты
- Один список: фильтр «Все» / «Прочитано».
- Прочитанные помечены; порядок стабильный.
- Текст: чтение, фуригана, тап по слову → словарь.
- «Прочитано» ставится автоматически после чтения/урока; можно отметить вручную.

### Нижний лист словаря
- Открывается поверх текста.
- Не теряет позицию чтения.
- Кнопка «Добавить в колоду» и состояние «Уже в колоде».
- Закрытие — свайп/кнопка/назад.

### Текст
- Заголовок, уровень.
- Текст с токенами и фуриганой.
- Переключатель фуриганы.
- Перевод — по кнопке.
- Тап по слову → нижний лист.
- Прогресс чтения (позже).

### Повторение
- Отдельный stack-экран, не таб.
- Основной запуск — после каждого урока; также с Главной и из словаря.
- Лимит — до 10 слов за сессию (настраиваемый).
- Карточка → «Показать ответ» → ответ + контекст → 4 оценки.
- Прогресс сессии и итог.
- Если due-карточек нет — «на сегодня всё» и следующий срок.

### Настройки / О приложении
- Фуригана вкл/выкл.
- Тема (позже).
- «Источники»: JMdict/EDRDG, jmdict-simplified, лицензии, версии.
- Экспорт/импорт (позже).
- Версия приложения.

## Состояния

Для каждого экрана:
- **Loading** — короткий, без ложной активности.
- **Empty** — объяснение, что делать.
- **Error** — что случилось и как исправить.
- **Offline** — не ошибка; приложение работает.
- **Content missing** — понятное сообщение, не белый экран.

## Визуальный язык

- Спокойная палитра, высокий контраст текста.
- Светлая тема: основной accent — тёмный розово-красный (`#B33A56`) с белым текстом; мягкий фон — персиковый (`#FBE3DF`); для мелкого текста/активных табов — `#A63D56`.
- Тёмная тема: фон `#171214`, surface `#221A1D`, accent — светлый розовый (`#FFA3B4`) с тёмным текстом, accentSoft `#3B232A`, accentStrong `#FFB3C1`.
- Логика контраста: в светлой теме кнопка темнее ради белого текста, в тёмной — светлее ради тёмного. Тема следует системной схеме (`userInterfaceStyle: automatic`); ручного переключателя пока нет.
- Один акцентный цвет для действий/прогресса; остальные цвета — служебные.
- Японский текст — крупнее обычного, с достаточным межстрочным интервалом.
- Системный японский шрифт на старте; кастомный шрифт — только если размер оправдан.
- Токены/фуригана — аккуратная типографика, без «прыгающей» верстки.
- Анимации — короткие, по делу; уважать reduce motion.
- Haptics — опционально, не обязательны.

## Геймификация

Допустимо:
- прогресс урока;
- счётчик due;
- серия дней (позже);
- мягкая похвала за завершение.

Не делать:
- таймеры, которые наказывают;
- жизнь/энергию;
- агрессивные push-уведомления;
- рейтинги и соцсоревнования;
- бесконечные награды, отвлекающие от учёбы.

## Доступность

- Touch-цели не меньше 44×44.
- Контраст текста/фона.
- Поддержка dynamic type.
- Accessibility labels для японских токенов: поверхность + чтение.
- Не полагаться только на цвет для правильного/неправильного ответа.
- Reduce motion.

## Локализация

- UI — язык системы с fallback на русский; сейчас поддерживается только `ru`.
- Все строки — в `src/i18n/`, не в JSX.
- Японский контент — с чтением и русским переводом.
- Позже — словарь строк и второй язык интерфейса.
- Не хардкодить русские строки в компонентах.

## Ограничения дизайна

- Android-телефон, Expo Go.
- Без кастомных нативных модулей в MVP.
- Офлайн: никаких обязательных сетевых экранов.
- Средний телефон: не тянуть тяжёлые анимации и списки.
