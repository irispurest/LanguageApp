# 02. Требования

Приоритеты: **MVP** — первый вертикальный срез; **Next** — сразу после MVP; **Later** — после стабилизации.

## Функциональные требования

### Контент и course packs

| ID | Требование | Приоритет | Критерий приёмки |
|---|---|---|---|
| C-01 | Приложение загружает course pack из локального JSON | MVP | Урок отображается без сети |
| C-02 | Course pack валидируется схемой до сборки/запуска | MVP | Невалидный урок не попадает в сборку, ошибка понятна |
| C-03 | У контента стабильные ID | MVP | Прогресс не теряется при редактировании текста урока |
| C-04 | Поддержка версии схемы и версии пака | MVP | Несовместимая версия даёт понятную ошибку |
| C-05 | Добавление нового урока без изменения UI-кода | MVP | Достаточно добавить JSON и запись в манифест |
| C-06 | Несколько языков через language adapter | Later | Второй язык не требует копирования приложения |
| C-07 | Импорт/скачивание паков | Later | Пак можно добавить без обновления приложения |

### Грамматические уроки

| ID | Требование | Приоритет | Критерий приёмки |
|---|---|---|---|
| G-01 | Урок содержит объяснение, примеры и упражнения | MVP | Все блоки отображаются |
| G-02 | Урок можно пройти последовательно | MVP | Есть переход «дальше/назад», выход с сохранением |

| G-04 | Прогресс сохраняется после каждого ответа | MVP | Перезапуск не теряет данные |
| G-05 | Можно повторить урок | MVP | Повторный проход не ломает историю |
| G-06 | Грамматические точки позже становятся карточками SRS | Later | Грамматика появляется в очереди повторений |

## Нефункциональные требования

### Офлайн и приватность
- Все основные сценарии работают в авиарежиме.
- Нет обязательного логина.
- Нет аналитики и трекинга в MVP.
- Сетевые запросы в runtime отсутствуют; исключение — будущая явная загрузка контента.

### Производительность
- Запуск приложения и открытие урока — без заметных задержек на среднем Android-телефоне.
- Поиск по словарю — с ограничением выдачи и индексами.
- Не загружать весь словарь в память.
- Целевой размер установки: измерить на первом билде; ориентир — до 100 МБ, по возможности меньше. Тяжёлые паки — отдельно.

### Надёжность
- Записи прогресса и ответов — транзакционно.
- Миграции только вперёд, с проверкой версии.
- Ошибка одного урока не должна ронять всё приложение.
- Нет «тихих» потерь данных.

### Доступность
- Крупные touch-цели, читаемый контраст.
- Поддержка системного размера шрифта.
- Японские токены имеют accessibility-подпись с чтением.
- Уважать reduce motion.

### Поддерживаемость
- TypeScript strict.
- Маленькие модули, явные интерфейсы.
- Контент отделён от UI.
- Критичная логика покрыта тестами.
- Новые зависимости — только с обоснованием.

## Вне scope MVP

- iOS.
- Бэкенд, синхронизация, аккаунты.
- Соцфункции, рейтинги, чаты.
- AI-генерация уроков.
- Рукописный ввод и распознавание кандзи.
- Аудио/произношение.
- Полноценный визуальный конструктор курсов.
- Веб-версия.
- Монетизация.
