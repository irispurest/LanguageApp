# Документация проекта

Это проектная документация приложения для изучения языков (первый — японский). Код ещё не создан: документы фиксируют целевое состояние, архитектуру, контент и план работ.

## Статус

- Стадия: app shell, схема контента, localization foundation и контент `は`/`が` готовы.
- В репозитории: Expo-приложение с Expo Router, Zod-схемы, CLI, курс `ja-ru`, `AGENTS.md`, `docs/`.
- Следующий шаг: экран урока и упражнения, затем SQLite-прогресс.

## Термины

- **Course pack** — версионированный набор контента (уроки, тексты, упражнения) для языка.
- **Language adapter** — код, специфичный для языка; для японского: кана, кандзи, фуригана, токенизация.
- **SRS** — spaced repetition system, интервальные повторения.
- **FSRS** — современный алгоритм SRS; используем через библиотеку `ts-fsrs`.
- **Token** — единица текста (слово, частица, пунктуация) с поверхностью, леммой и чтением.
- **Lemma** — словарная форма слова.
- **Deck** — колода карточек для повторения.
- **Card** — карточка (слово или грамматическая точка) с состоянием планировщика.
- **Review log** — запись ответа и пересчёта карточки.

## Принципы документации

- Документы — источник истины по дизайну; код — по фактическому поведению.
- При изменении решения обновляй соответствующий документ и [`13-decisions.md`](13-decisions.md).
- Не добавляй сюда секреты, ключи и персональные данные.
- Если документ и код расходятся, сначала выясни причину, затем обнови документ или код.
